If Windows warns you

Windows SmartScreen flags all new unsigned software downloaded from the internet. ST-SoftwareTool is completely safe. To install:

  1. Click More info on the blue SmartScreen screen
  2. Click Run anyway

Alternatively: right-click the downloaded file → Properties → tick Unblock → OK, then run it.

Requirements
  • Windows 10 / 11 (64-bit)
  • Administrator rights for full feature access
  • NVIDIA GPU recommended for GPU monitor
Why does Windows warn me?

Microsoft SmartScreen checks every downloaded .exe against a reputation database. New software with few downloads is flagged automatically regardless of whether it is safe.

ST-SoftwareTool has no ads, no tracking and no account, and it never sends your files or personal data to us. It only goes online to check for updates, look up file fingerprints for the antivirus, show your IP address, and run the VPN when you connect — see the Privacy Policy. Apart from blocking critical threats (which you can turn off in Settings), it only changes your system when you ask it to.

If macOS blocks it

The first time you open it, macOS says “Apple could not verify ‘ST-SoftwareTool’ is free of malware…” It shows this for every app that isn’t in Apple’s paid developer program. To open it:

  1. Click Done (not Move to Trash)
  2. Open System Settings → Privacy & Security
  3. Scroll down to “ST-SoftwareTool was blocked…” and click Open Anyway
  4. Click Open Anyway again and enter your Mac password

You only need to do this once — after that, and after updates, it opens normally.

Requirements
  • macOS 12 Monterey or newer
  • Any Apple Silicon Mac (M1 or newer, or A18 Pro in MacBook Neo) or an Intel Mac
  • Services and Device Settings are Windows-only for now
Why does macOS warn me?

macOS Gatekeeper shows this warning for every app that isn’t registered with Apple’s paid developer program. It says nothing about whether the app is safe.

ST-SoftwareTool is free, and every macOS version is built automatically from the public source code on GitHub.
